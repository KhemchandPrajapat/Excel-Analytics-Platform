# Excel-Analytics-Platform
A modern web-based Excel Analytics Platform for data visualization, smart chart system, dashboard creation, and smart report generation.
A powerful full-stack web platform that allows users to upload any Excel file (.xls or .xlsx), analyze the data, and generate interactive 2D and 3D charts in real time.
Built using the MERN stack, this project combines data visualization, analytics, and AI-powered insights in one seamless interface.


---

🚀 Features

🧮 For Users

Upload Excel files (.xls or .xlsx) easily.

Automatically display and analyze data in a structured format.

Choose X and Y axes dynamically from column headers.

Generate interactive 2D and 3D charts (Bar, Line, Pie, Doughnut, Area, Scatter, etc.).

Download generated charts in image format.

Access personal dashboard showing upload history and analysis reports.


🛠 For Admin

Manage users, uploaded files, and platform usage.

Monitor analytics and user activity logs.


🤖 AI Integration (Optional)

Get smart insights and summary reports automatically from the uploaded Excel data.

Uses AI APIs to interpret trends, outliers, and correlations in the dataset.


How It Works

1. Upload an Excel file from your device.


2. The system reads and previews the data.


3. Select columns for X and Y axes.


4. Choose chart type (e.g., Bar, Line, 3D Surface).


5. Generate and download interactive visualizations.


6. View and manage your analysis history on your dashboard.
